# Telegram-бот с расписанием баскетбольных матчей

1. Название и цель проекта
Название: NBA scout.
Цель: Бот помогает следить за расписанием матчей и статистикой игроков, турнирной таблицей, и собирает всю информацию в одном месте.

2. Список команд бота
Команда	Что делает
/start	Приветствие, показ главного меню
/help	Краткая инструкция по боту
/cancel	Выход из любого текущего сценария (FSM)
/table, /t Турнирная таблица NBA
/conf Турнирная таблица конференций
/schedule Расписание матчей лиги
/favorite Команды, за которыми наблюдает пользователь
/subscribe Подписка на команду
/unsubscribe Отписка от команды
/stats Посмотреть статистику игрока


3. Пользовательские сценарии (user flow)
Сценарий "Посмотреть расписание команды":
1. Пользователь нажимает "Расписание" на главном меню
2. Бот показывает inline-клавиатуру со списком команд
3. Пользователь выбирает команду
4. Бот показывает второй урвоень inline-клавиатуры: "ближайшие игры" / "последние результаты"
5. Бот делает запрос к API
6. Бот формирует ответ и присылает расписание из 3-5 игр, указывает дату, время игры (если еще не сыграна) или счет (если игра завершена)
7. Пользователю предлагаются кнопки "Подписаться на эту команду" / "Назад в меню" 

Сценарий "Подписка на команду":
1. Пользователь нажимает "Подписаться на команду" (на главном меню или из п.7 выше)
2. Бот показывает inline-клавиатуру со списком команд
3. Пользователь выбирает команду
4. Бот добавляет команду в json по user_id (если ее ещё там нет)
5. Бот отправляет сообщение пользователю о завершении операции и показывает inline-клавиатуру с кнопкой "Мои команды"

Сценарий "Мои команды":
1. Пользователь нажимает "Мои команды" на главном меню
2. Бот по user_id берет список команд из json-файла
3. Если список пуст, то бот сообщает пользователю, что список пуст и предлагает подписаться на какую-нибудь команду. 
4. Если список не пуст, то бот отправляет пользователю список команд и inline-клавиатуру у каждой команды с возможностью отписаться

Продумай также:

Что произойдёт, если пользователь введёт что-то неожиданное на любом шаге?
Бот будет отвечать сообщением: 'Выберите вариант из клавиатуры!' на произвольный текст.

Как пользователь может отменить сценарий на середине?
Бот будет сбрасывать текущее состояние без подтверждения пользователя и выполняет только что отправленную команду.

4. Структура данных (JSON)

Файл: subscriptions.json

Формат (уже определён — не меняй без причины, но объясни своими словами, почему он такой):

json
{
  "123456789": ["Lakers", "Celtics"],
  "987654321": ["Warriors"]
}
Ключ — уникальный идентификатор пользователя в telegram
Значение — список названий команд, на которые подписан пользователь

Вопрос на подумать: что должно происходить, если файла subscriptions.json ещё не существует (первый запуск бота)? Опиши логику: 
  Бот проверяет есть ли файл с названием subscriptions.json, если нет, то создает пустой файл

5. Внешний API

Сервис: balldontlie — бесплатное API с данными NBA (команды, игроки, игры).

Регистрация: создать аккаунт на app.balldontlie.io, ключ — в личном кабинете.

Лимит бесплатного тарифа: 5 запросов в минуту на один ключ.

Основной эндпоинт, который понадобится:

GET https://api.balldontlie.io/v1/games

с параметрами для фильтрации по команде/дате (см. документацию).

Задание: сделай один тестовый запрос (через браузер, curl или Postman) и вставь сюда сокращённый пример реального ответа — 1 объект игры из data, не весь список:

json


По этому ответу определи и запиши:

В каком поле лежит дата/время игры: [ЗАПОЛНИ САМ]
В каком поле — домашняя и гостевая команда: [ЗАПОЛНИ САМ]
В каком поле — счёт (если игра уже прошла): [ЗАПОЛНИ САМ]

Если решите использовать несколько API-ключей (ротация для обхода лимита 5 запросов/мин): Количество ключей: [ЗАПОЛНИ САМ] Как будет выбираться ключ при каждом запросе (опиши логику словами): [ЗАПОЛНИ САМ]

9. Итог одним абзацем

 Этот бот предназначен для болельщиков NBA, которым важно знать расписание матчей, результаты команд и положение в турнирной таблице. Он умеет запоминать твои любимые команды, показывать их ближайшие и прошедшие матчи. Все файлы хранятся локально, а интерфейс в большинстве построен на Inline-клавиатурах, что убирает лишний текст и ручной ввод. Целева аудитория - фанаты баскетбола, которым важно удобство в одном месте
